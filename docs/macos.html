macOS

The same setup as far as macOS allows: same fonts (24 pt, 3x the pixel grid on Retina), themes, Emacs and keys, with cmd as dwm's Super and a Mac tool in place of each Linux one. Config lives in desktop/mac; the full guide is chapter 13 of the manual.

Linux → Mac

dwm → AeroSpaceSame keys, workspaces 1–10 summoned like tags; skhd adds cmd-left/right, which AeroSpace cannot see.
dwm borders → JankyBordersColours from theme.
dwmblocks → SketchyBarTags with app icons, weather, network, input method, memory, battery and date, in the theme's bar colours.
dmenu → dmenu in SwiftSame flags and keys, drawn over the bar. Typing firefox opens a new window.
st → kittyst's keys: alt-l open a link, alt-y copy one, alt-o copy the last command's output. One kitty process, so a window opens in 0.2 s.
dwm swallow → swallowAn app started from a terminal hides that terminal until it exits, through an AeroSpace rule and a zsh hook.
zathura → zathuraFrom Homebrew, with Zathura.app so Finder opens PDF, EPUB and MOBI in it.
keyd → KarabinerRules generated from the same keyd.conf.
fcitx5 → SquirrelThe same Rime schemes.
getpass → getpasspass + dmenu, with pinentry-mac.
dunst, slock, flameshotNotification Center, ctrl-cmd-q, cmd-shift-5.
redshift → f.lux
playerctl, pulsemixernowplaying-cli, switchaudio-osx.
— → CodeIslandClaude Code / Codex status around the notch.
