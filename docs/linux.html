Linux

Debian/Ubuntu with dwm on X11, started from gdm or startx. The suckless tools are my own forks, built into /usr/local by bootstrap.sh suckless. Config lives in desktop/linux and Dotfiles.

desktop/linux on GitHub ↗All Linux apps ↓

The desktop

dwmTiling window manager, tags 1–9 per monitor.
dwmblocksThe status bar: the blocks are scripts in desktop/linux/scripts/.
dmenuLauncher and the base of the helper menus (emoji, passwords, mounting drives).
stTerminal. Alacritty is installed and themed too.
slockScreen lock (no keybinding: run slock).
dunstNotifications.
keydThe home-row keymap, system-wide: /etc/keyd/default.conf links to keymap/linux/keyd.conf.
fcitx5 + RimeChinese input with the Rime schemes.
cursorsGenerated per theme by theme.
