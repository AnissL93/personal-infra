Architecture

    
One parent repo holds the install machinery. Each part of the setup is its own repo, pulled in as a git submodule. To change a part, commit and push inside its submodule first, then record the new version in the parent.

One home-row layout on every machine: keyd on Linux, Karabiner rules generated from the same file on macOS.
