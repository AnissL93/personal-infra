# Config symlinks; `bootstrap.sh links` creates the rows for this machine's platform.
# Format: PLATFORM SOURCE TARGET
#   PLATFORM  L (Linux), M (macOS) or LM (both)
#   SOURCE    path in this repo; TARGET: where it is linked (~ = $HOME). No spaces in paths.
# An existing TARGET is kept as TARGET.bak-<date>. Firefox's profile files are linked by the
# step itself (the profile folder name differs per machine), and so are macOS targets under
# ~/Library/Application Support (VS Code).

# paths that scripts refer to
LM  dotfiles                                  ~/System/dotfiles
